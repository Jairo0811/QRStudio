# Changelog

Todos los cambios relevantes de QR Studio se documentan en este archivo.

## [1.0.0] - 2026-09-23

### Added

- Metadata final de producto y versión 1.0.0.
- Icono propio para la aplicación.
- Publicación self-contained para Windows x64.
- Paquete portable ZIP.
- Instalador mediante Inno Setup.
- Checksums SHA-256 de los paquetes finales.
- Automatización de GitHub Release.
- Licencia MIT.
- Documento de estado final y notas de versión.

### Changed

- El proyecto pasa de estado “en desarrollo” a “congelado”.
- Se elimina de la interfaz el acceso deshabilitado al futuro lector QR.
- El roadmap se cierra y las funciones 1.1/2.0 pasan a no planificadas.

### Included from 0.1

- Aplicación WPF con patrón MVVM e inyección de dependencias.
- Generación para texto, web, correo, teléfono y SMS.
- Personalización de colores, escala, corrección y zona de seguridad.
- Exportación PNG.
- Historial local persistente y reutilizable.
- Pruebas automatizadas y CI.

### Removed

- Aplicación WinForms original en .NET Framework 4.7.1.
- Dependencias antiguas y referencias locales no reproducibles.

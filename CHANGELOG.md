# Changelog

Todos los cambios relevantes de QR Studio se documentarán en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto adoptará versionado semántico a partir de su primera versión estable.

## [Unreleased]

### Added

- Nueva solución QR Studio en .NET 10.
- Aplicación WPF con patrón MVVM e inyección de dependencias.
- Generación para texto, web, correo, teléfono y SMS.
- Personalización de colores, escala, corrección y zona de seguridad.
- Exportación PNG.
- Historial local persistente y reutilizable.
- Pruebas automatizadas.
- Flujo de integración continua.

### Removed

- Aplicación WinForms original en .NET Framework 4.7.1.
- Dependencias antiguas y referencias locales no reproducibles.
